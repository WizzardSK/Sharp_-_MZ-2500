# Sharp_-_MZ-2500

Thumbnails for Sharp MZ-2500 software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `mz2500` software list has them.

Snaps from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/).
