# Sharp_-_MZ-2500

Thumbnails for Sharp MZ-2500 software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `mz2500` software list has them.

Snaps from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/), scaled to 640x480: the MZ-2500 draws 640x200 and 320x200 pictures with tall pixels, and the snaps are taken at that size, so they came out squashed. Snaps that show only a loading error or a loading screen are left out.
